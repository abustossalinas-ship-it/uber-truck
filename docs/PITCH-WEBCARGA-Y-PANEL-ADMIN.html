3. Panel admin — visión operativa (KPIs, NPS, viajes)

Estado: no implementado en app v0.0.57. Hoy el fundador exporta desde Supabase o revisa casos en moderación de multas. Este apartado define el producto admin para piloto M2 y escala.

3.1 Objetivo

Un rol admin ve en un solo lugar todos los viajes y la salud del marketplace: volumen, conversión, tiempos, cancelaciones, ingreso estimado (take rate), satisfacción (NPS/★) y alertas — sin depender de SQL manual cada semana.

3.4 API sugerida (implementación futura)

  • GET /api/admin/dashboard?from=&to=&corridor= — JWT role=admin, agregados.
  • GET /api/admin/trips — paginado, filtros estado/fecha/empresa.
  • GET /api/admin/kpis — series temporales (semana) para gráficos simples.
  • POST /api/admin/surveys/nps — opcional: cargar NPS post-viaje manual en piloto.
